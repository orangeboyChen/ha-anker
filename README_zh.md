# Anker 蓝牙充电宝 Home Assistant 集成

此自定义集成通过本地蓝牙读取 Anker A110A Prime 充电宝，并通过 Anker 云端 MQTT 读取 A2345 250W Prime Charger。蓝牙设备提供电量和连接实体，Wi-Fi 充电器提供各 USB 端口的电压、电流和功率遥测。

## 安装

1. 在 HACS 的自定义仓库中添加 `https://github.com/orangeboyChen/ha-anker`，类别选择 Integration。
2. 安装 **Anker BLE Power Bank** 并重启 Home Assistant。
3. 在“设置 → 设备与服务”添加集成，使用 Anker 账号登录后直接从账号设备列表选择型号。A110A 使用 Anker 返回的蓝牙地址走本地 BLE；云充电器走 MQTT。附近 FF09 设备仍可通过自动发现直接添加。
4. 让充电宝处于 HA 主机或蓝牙代理的覆盖范围内。

蓝牙路径使用 Home Assistant 本地蓝牙；A2345 云端路径会在配置时请求 Anker 账号，不需要手机 App 或 HAR 会话凭据。

## 当前支持范围

- A110A 蓝牙：GATT 发现、FF09 GCM 会话、电量快照和实时通知。APK 定义的应用层字段（总输入/输出功率、C1/C2/USB-A 电压电流功率、健康度、循环次数、电池/外壳温度）已建立稳定的 HA 实体 ID，默认禁用；在对应 A110A TLV 和换算规则确认前保持不可用，不会把原始字节猜成数据。
- 手动连接控制：连接按钮立即恢复更新；断开按钮关闭 GATT 并暂停自动重连。
- `raw_fields` 保留遥测 TLV，但不猜测未知字段的含义和比例。
- A2345 云端 MQTT：登录后获取临时 mTLS 凭据，发送状态请求，并创建六个 USB 端口遥测实体（C1–C4、A1、A2）。每个端口提供原始状态值、电压、电流和功率；参考仓库确认的写入项包括五个继电器选择器（C1–C4 与合并的 USB-A 轨）、四路优先级 bitmask，以及四种非自定义充电模式（AI Power、连接优先、双笔记本、低功耗）。每次写入后立即重新读取，若目标状态没有出现则 HA 操作报错。回读与请求一致只能作为状态证据，不能称为设备独立 ACK。另有基于完整端口数据计算的总电流、总功率和非零状态数量，以及保留响应全部字段的诊断实体。MQTT 会话和临时证书只保留在内存中。
- `cloud_auth.py` 和 `config_flow.py` 支持账号缓存与多设备选择，不保存密码；同一次 HA 运行期间输入过的密码可用于自动续期。会话失效时会删除缓存账号，需要重新添加。
- 已验证 A2345 MQTT 连接、状态读取、ZX 命令编码和同值回读路径；继电器、优先级和四种非自定义充电模式均按参考仓库的命令映射接入，并且不会把回读误称为独立 ACK。自定义协议、定时器、屏幕/主题设置仍未开放；重置、OTA、Wi‑Fi 切换和解绑不会由集成触发。

A110A 的功率、电流、电压、温度、健康度和循环次数实体会在对应协议字段被确认后变为可用。在此之前它们保持不可用；相关原始字段仍可在电量传感器属性中查看，集成不会猜测未知 TLV 的含义。

## 开发

```sh
uv sync
uv run ruff format .
uv run ruff check .
uv run pytest
```

协议测试完全离线，不会连接实体设备或发送控制命令。
