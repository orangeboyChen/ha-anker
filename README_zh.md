# Anker 蓝牙充电宝 Home Assistant 集成

此自定义集成通过本地蓝牙读取 Anker A110A Prime 充电宝，并通过 Anker 云端 MQTT 读取 A2345 250W Prime Charger。蓝牙设备提供电量和连接实体，Wi-Fi 充电器提供各 USB 端口的电压、电流和功率遥测。

## 安装

1. 在 HACS 的自定义仓库中添加 `https://github.com/orangeboyChen/ha-anker`，类别选择 Integration。
2. 安装 **Anker BLE Power Bank** 并重启 Home Assistant。
3. 在“设置 → 设备与服务”添加集成。附近的 FF09 设备会自动发现，也可以手动输入蓝牙地址；手动添加不要求设备当时在线，设备实体会先创建，之后由 HA 蓝牙重新连接。云端路径设计为输入 Anker 邮箱/密码、复用缓存账号、自动刷新会话，然后从一个账号下选择多台设备。
4. 让充电宝处于 HA 主机或蓝牙代理的覆盖范围内。

蓝牙路径使用 Home Assistant 本地蓝牙；A2345 云端路径会在配置时请求 Anker 账号，不需要手机 App 或 HAR 会话凭据。

## 当前支持范围

- A110A 蓝牙：GATT 发现、FF09 GCM 会话、电量快照和实时通知。
- 手动连接控制：连接按钮立即恢复更新；断开按钮关闭 GATT 并暂停自动重连。
- `raw_fields` 保留遥测 TLV，但不猜测未知字段的含义和比例。
- A2345 云端 MQTT：登录后获取临时 mTLS 凭据，发送状态请求，并创建六个 USB 端口的遥测实体和受回读校验保护的端口开关。每个端口提供原始状态值、电压、电流和功率；开关候选使用 APK 已恢复的 `0x0144/0x0146` setting map，发送后立即重新读取，若目标状态没有出现则 HA 操作报错。端口优先级候选使用已恢复的四端口低 4 位 bitmask，并在 `param_info` 回读后以 HA 选择实体开放（选项 `0`–`15`）。回读与请求一致只能作为状态证据，不能称为设备独立 ACK。另有基于完整端口数据计算的总电流、总功率和非零状态数量，以及保留响应全部字段的诊断实体。MQTT 会话和临时证书只保留在内存中。
- `cloud_auth.py` 和 `config_flow.py` 支持账号缓存与多设备选择，不保存密码；同一次 HA 运行期间输入过的密码可用于自动续期。会话失效时会删除缓存账号，需要重新添加。
- 已验证 A2345 MQTT 连接、状态读取、候选 setting 发布和同值回读；对有输出读数的端口做关→开测试时，状态没有跟随请求，因此当前不能宣称端口继电器写入已被设备接受。充电模式、自定义协议、定时器和屏幕设置仍只保留离线编码/静态证据，尚未作为实体开放。重置、OTA、Wi-Fi 切换和解绑不会由集成触发。

功率、电流、电压、温度、电池健康度和循环次数的 A110A TLV ID/换算规则尚未验证，所以暂不创建独立实体；相关原始字段可在电量传感器属性中查看。

## 开发

```sh
uv sync
uv run ruff format .
uv run ruff check .
uv run pytest
```

协议测试完全离线，不会连接实体设备或发送控制命令。
